STUDIO VONDERLIJN - fictieve demo-website
=========================================

Open index.html in je browser. Alle menu-links, knoppen en kaarten
verwijzen naar een bestaande pagina in deze map, dus je kunt de hele
site doorklikken.

Pagina's:
  index.html            Home
  diensten.html         Diensten, werkwijze, tarieven
  werk.html             Projectoverzicht + klantreacties
  case-meridiaan.html   Uitgewerkte case
  over.html             Over het team
  contact.html          Contactformulier (demo)
  styles.css            Vormgeving
